# Python Tetris

This is the repository with non-finished implementation of the tetris. Please, be patient because I am writing it in my free time :-).

### Prerequisites

The game is based on the pygame library. You can install it using the pip tool.

```
pip3 install --user pygame
```

Provided code is written for Python3. After that, you can run the game with:

```
python3 tetris.py
```


## Controls

The following list contains the control keys:

* *Left / Right Arrows* - move the active block horizontally
* *Down Arrow* - move the active block down (soft drop)
* *Up Arrow / Space* - rotate the active block
* *p* - pause / continue the game
* *q* - quit the game

## Running Tests

To run the unit tests:

```bash
pytest
```
